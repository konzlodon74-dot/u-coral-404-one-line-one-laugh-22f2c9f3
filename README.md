## What it does

`main.py` (Python 3, standard library only) writes a single original funny
line — at most 200 characters, no title, no setup, no explanation — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) with no trailing
newline.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
